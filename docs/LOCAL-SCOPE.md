# Personal command center scope

The user's latest clarification supersedes the execution/commercial requirements in the original PRD. The application monitors and organizes external developments; it does not install or operate what it researches.

## Included

- Public model metadata from Hugging Face and Ollama, source-attributed comparisons, release/popularity observations and saved research.
- Robotics and other domain news, papers, demonstrations, ideas, research notes and watchlists.
- Personal notes, tasks, records, read-only project observation, local search, backups and optional peer sync.
- Approved MCP information and separately authorized provider integrations.
- Deterministic record briefings without AI. Optional reviewed cloud AI is separate and requires a provider key.

## Excluded from the code score

- Downloading, installing or running local LLMs; local embedding runtimes.
- Robot/simulator setup and hardware operation; generated prototype execution.
- Production signing/notarization, app-store submission, public onboarding, commercial licensing and managed marketplace hosting.
- Independent review and end-to-end acceptance testing: tracked as verification, not coding completion.

## Implementation notes

Model-management and local inference commands are no longer registered in desktop IPC. Assistant offers only separately approved cloud requests. Previously saved automation/agent analysis steps now compile selected-record briefings and evidence without inference; legacy model fields are ignored. Existing records and historical results are retained. Briefings label themselves as deterministic and do not claim to answer research questions.

Ollama ingestion reads bounded public HTML metadata and caches at most 30 official-library model entries per response. It never requests registry blobs or model weights. Provider layout changes fail visibly and preserve the existing cache. Catalogue position is not a quality benchmark. Hugging Face observed download-count changes are differences in provider snapshots, not guaranteed new downloads or independently verified trends.

## Dependency boundaries

Public model/research/news metadata needs internet and source availability, not model installation or an AI key. YouTube/private accounts/banking/optional cloud AI may require credentials. MCPs require endpoint approval and any provider-specific authentication. Ownership, opt-in after-quit reminders, streaming archives, research collections, background Google refresh and the cached research radar now exist in source. The remaining-code pass adds bounded scholarly/scheme adapters, record AI exclusions, acknowledged sync compaction, selected-field large-archive restore, streaming WebDAV, statement reconciliation and mobile reminder receipt coordination. External provider access/source availability and independent runtime acceptance remain separate. See the HTML report for every task's current score and remaining work.

## November 15 clarification

Email/calendar remains Google-only. Poker Hub provides a worldwide current/upcoming search query plus organizer-specific shortcuts; this is search planning, not a claim to have aggregated every tournament. Existing calendars show all configured sources together and retain ongoing multi-day events. The active AI assistant remains online-only; local inference/runtime code is preserved outside active build paths for later user-authorized configuration. The floating assistant launcher is draggable inside the app and saves only its position in local UI storage. API keys must be entered directly in the application secure-store setup.

## Primary workflow clarified on 2026-11-16

One aggregated topic feed is the app's core experience: monitor external models, repositories, news, research, libraries, lectures, videos, social posts and upcoming events; then save selected information, write/upload related documents and start workspace work. The owner chose worldwide with US/India filters, keyless public YouTube channels, and confirmed no X/LinkedIn developer API access. See [Discovery aggregation](DISCOVERY-AGGREGATION.md) for current coverage, actual live evidence and social access limits.

The code score covers these concrete bounded behaviors; it does not claim arbitrary merchant/store/IDE support, complete state scheme/current patent coverage, universal natural-language understanding, automatic factual proof, forensic erasure, inline preview of every file format, or exactly-once alerts across offline devices. These limits are explicit in each feature and report.
