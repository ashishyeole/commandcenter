# Personal command center scope

The user's latest clarification supersedes the execution/commercial requirements in the original PRD. The application monitors and organizes external developments; it does not install or operate what it researches.

## Included

- Public model metadata from Hugging Face and Ollama, source-attributed comparisons, release/popularity observations and saved research.
- Robotics and other domain news, papers, demonstrations, ideas, research notes and watchlists.
- Personal notes, tasks, records, read-only project observation, local search, backups and optional peer sync.
- Approved MCP information and separately authorized provider integrations.
- Deterministic record briefings without AI. Optional reviewed cloud AI is separate and requires a provider key.

## Excluded from the code score

- Downloading, installing or running local LLMs; local embedding runtimes.
- Robot/simulator setup and hardware operation; generated prototype execution.
- Production signing/notarization, app-store submission, public onboarding, commercial licensing and managed marketplace hosting.
- Independent review and end-to-end acceptance testing: tracked as verification, not coding completion.

## Implementation notes

Model-management and local inference commands are no longer registered in desktop IPC. Assistant offers only separately approved cloud requests. Previously saved automation/agent analysis steps now compile selected-record briefings and evidence without inference; legacy model fields are ignored. Existing records and historical results are retained. Briefings label themselves as deterministic and do not claim to answer research questions.

Ollama ingestion reads bounded public HTML metadata and caches at most 30 official-library model entries per response. It never requests registry blobs or model weights. Provider layout changes fail visibly and preserve the existing cache. Catalogue position is not a quality benchmark. Hugging Face observed download-count changes are differences in provider snapshots, not guaranteed new downloads or independently verified trends.

## Dependency boundaries

Public model/research/news metadata needs internet and source availability, not model installation or an AI key. YouTube/private accounts/banking/optional cloud AI may require credentials. MCPs require endpoint approval and any provider-specific authentication. Ownership, opt-in after-quit reminders, streaming archives, research collections, background Google refresh and the cached research radar now exist in source. Remaining gaps include additional provider adapters, advanced policy/retention, per-record large-archive merging and selected mobile/financial workflows. See the HTML report for every task's current score and remaining work.
