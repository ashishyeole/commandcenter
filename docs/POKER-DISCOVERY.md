# Current and upcoming poker discovery

Poker Hub builds a worldwide tournament/festival/satellite search, with optional location and phrase, a 1–12 month planning window and year rollover. The first query has no provider restriction. Named shortcuts cover WSOP/Circuit, WPT/Prime, PokerStars Live/EPT/regional tours, APT and RunGood. They are a starting directory, not exhaustive coverage. No API key is needed to prepare or open a public web search.

Search queries are prepared locally. Opening Google/Bing sends only the displayed query. Search engines may return old articles or past tournaments; the year/window is a search hint, not an exact event-date filter. Verify start/end dates on publisher schedules. No tournament registration, payment or account access is performed.

Configured calendar results merge all sources by default. Ended and cancelled events are hidden; multi-day events remain visible through their end. All-day calendar end dates are exclusive. Unknown end dates use the start date rather than inventing a duration. Saved poker records use their recorded start/end dates; undated research remains available. Calendar recurrence support remains bounded as described in the status report.
